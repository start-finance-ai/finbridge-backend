# FinBridge 합성 데모 데이터

`finbridge_demo.json`의 6건은 직접 작성한 기능 시연용 예제입니다. 실제 지원사업이나 신청 가능한 공고가 아닙니다. 실제 기관, 문의처, 신청 링크, 공고 원문을 포함하지 않습니다.

`finbridge_dataset.kind = synthetic_demo`이면 정규화된 API 응답의 `source`는 `DEMO`입니다. 제목에도 `[데모]`를 표시합니다. 연령·업력·지역 비교, 신청기간과 마감 상태, 정보 부족 처리를 시연하기 위한 데이터이며 실데이터 평가 성능을 나타내지 않습니다.

외부 데이터는 별도 파일로 지정해 사용할 수 있습니다. 외부 데이터를 사용할 때는 해당 제공기관의 이용조건과 최신성을 확인해야 합니다.
